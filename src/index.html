Open-source systems engineering

Basaltwater

I designed and maintain Basaltwater, a toolkit for setting up and operating Debian machines, Proxmox guests, web services, and development workstations. It turns repeatable operations into inspectable commands with diagnostics and recovery paths. I use it to manage this website and my internal tools, services, and workstations.

Read the case study Explore the source (opens in a new tab) Getting started (opens in a new tab)

Machine setup

Compose server and workstation capabilities, provision Proxmox guests, manage service and network configuration, and diagnose hosts after setup.

Linux · Python · Proxmox · systemd

Safe deployments

Stage builds before release, isolate service accounts and writable state, check health at activation, and retain a path to roll back. SQLite services can receive consistent backups.

Deployment design (opens in a new tab)

Development environments

Prepare coding VMs with managed Git workspaces, browser testing, credentials, and clear privilege boundaries so changes can be developed, reviewed, and checked against running systems.
