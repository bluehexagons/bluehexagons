# Loren Crain / bluehexagons

I’m Loren Crain, a generalist software engineer and indie game developer in
southwest Missouri. I build web applications, games, creative tools, and
infrastructure.

I go by [bluehexagons](https://bluehexagons.com) online and am the solo developer
of Antistatic. I’ve worked professionally in financial technology, e-commerce, and
games.

## Released games

### [Antistatic](https://bluehexagons.com/antistatic.html)

[Antistatic on Steam](https://store.steampowered.com/app/944500/Antistatic) ·
[itch.io](https://bluehexagons.itch.io/antistatic) ·
[Humble Bundle](https://www.humblebundle.com/g/antistatic)

Antistatic is a competitive platform fighter. I built the game and its custom
C and TypeScript engine, and made the animation, 3D art, music, and sound.

The game’s repositories include the
[lobby server](https://github.com/bluehexagons/antistatic-server),
[animation tool](https://github.com/bluehexagons/antistatic-animator), and
[translation files](https://github.com/bluehexagons/antistatic-translations). The
[Trace language](https://github.com/bluehexagons/trace),
[@bluehexagons/easing](https://github.com/bluehexagons/easing), and
[Capacitor](https://github.com/bluehexagons/capacitor) also grew out of work on
the game.

### [End of Blackjack](https://store.steampowered.com/app/3884650/End_of_Blackjack/)

End of Blackjack is a first-person blackjack game set in a post-apocalyptic
world, built in Godot.

## Professional experience

The Air Dash Online team hired me as lead programmer after seeing an early
Antistatic demo, then called Blastzone. We knew each other through the local

## Basaltwater

[Basaltwater](https://github.com/bluehexagons/basaltwater) is my toolkit for
setting up and managing Linux servers, workstations, and Proxmox guests. It
handles configuration, diagnostics, security hardening, web deployments, coding
agents, and browser automation. I use it to manage this website and my internal
tools, services, and workstations.

[Read about how I built Basaltwater](https://bluehexagons.com/basaltwater.html).

### Interactive tools and sandboxes

- [Easing Lab](https://github.com/bluehexagons/easing-sandbox) — a browser tool
  for plotting and combining easing curves.
  [Open the lab](https://bluehexagons.github.io/easing-sandbox/).
- [vector-pose](https://github.com/bluehexagons/vector-pose) — vector-based
  skeletal rigging and posing software for desktop and browser.
  [Try the browser edition](https://bluehexagons.github.io/vector-pose/).
- [Trace Sandbox](https://github.com/bluehexagons/trace-sandbox) — a browser
  environment for trying [Trace](https://github.com/bluehexagons/trace),
  a functional language I developed for Antistatic.
  [Open the sandbox](https://bluehexagons.github.io/trace-sandbox/).
- [Generator](https://github.com/bluehexagons/generator) — a deterministic,
  dependency-free plasma image generator for the browser.
  [Open Generator](https://bluehexagons.github.io/generator/).
- [Pixel Generator](https://github.com/bluehexagons/pixelgenerator) — a browser
  pattern toy made in 2010. [Try it](https://bluehexagons.github.io/pixelgenerator/).
- [Waveplayer](https://github.com/bluehexagons/waveplayer) — a TypeScript
  audio player with a waveform display and an
  [interactive demo](https://bluehexagons.github.io/waveplayer/).
- [Gomoose](https://github.com/bluehexagons/gomoose) — a small,
  self-contained Go web server.
