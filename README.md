## Released games

### [Antistatic](https://bluehexagons.com/antistatic.html)

A competitive platform fighter. Solo work: game design, programming, the custom
C/TypeScript engine, 3D art, animation, music, and sound.

[Steam](https://store.steampowered.com/app/944500/Antistatic) ·
[itch.io](https://bluehexagons.itch.io/antistatic) ·
[Humble](https://www.humblebundle.com/g/antistatic)

### [End of Blackjack](https://store.steampowered.com/app/3884650/End_of_Blackjack/)

First-person blackjack in a post-apocalyptic world, built in Godot. I handled
game development; [kikiala](https://kikiala.bandcamp.com/) made the music.

## Experience

My professional work spans financial technology, e-commerce, and games. At
Zazzle, I built frontend features and internal tools, including a Slate rich-text
editor. I was Air Dash Online’s sole programmer; teammates handled art and design,
with input from me on mechanics and design.

I work mainly with TypeScript, JavaScript, Go, C/C++, C#, SQL, React, Electron,
Godot, AWS, and Linux. See my [resume](https://bluehexagons.com/profile.html) for details.
