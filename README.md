# Loren Crain / bluehexagons

I’m Loren Crain, a generalist software engineer and indie game developer in
southwest Missouri. I build across the stack, from frontend and backend
applications to game engines, gameplay systems, creative tools, graphics, and
infrastructure.

I’m the person behind [bluehexagons](https://bluehexagons.com) and the solo
developer of Antistatic. My professional experience spans financial technology,
e-commerce, and games.

## Released games

### [Antistatic](https://bluehexagons.com/antistatic)

[Antistatic on Steam](https://store.steampowered.com/app/944500/Antistatic) ·
[itch.io](https://bluehexagons.itch.io/antistatic) ·
[Humble Bundle](https://www.humblebundle.com/g/antistatic)

Antistatic is a crisp, uncompromising platform fighter focused on exploring
competitive mechanics. I built the game and its custom C and TypeScript engine
as a solo project, including its animation, 3D art, music, and sound.

Antistatic’s related repositories include the [lobby server](https://github.com/bluehexagons/antistatic-server),
[animation tool](https://github.com/bluehexagons/antistatic-animator), and
[translation files](https://github.com/bluehexagons/antistatic-translations). The
[Trace language](https://github.com/bluehexagons/trace),
[@bluehexagons/easing](https://github.com/bluehexagons/easing), and
[Capacitor](https://github.com/bluehexagons/capacitor) also began as supporting
technologies for the game.

### [End of Blackjack](https://store.steampowered.com/app/3884650/End_of_Blackjack/)

End of Blackjack is an atmospheric first-person take on classic blackjack.
Built in Godot, it focuses on the rhythm of cards, machines, and risk in a
post-apocalyptic setting.

## Professional experience

At Zazzle, I worked extensively on public-facing and internal websites and
tools, including a full-featured rich-text editor built on Slate.

Antistatic predates Air Dash Online. Its team hired me as lead programmer after
seeing an early demo of the project—then called Blastzone—and knowing me through
the local competitive Super Smash Bros. scene.

## infra-tools

[infra-tools](https://github.com/bluehexagons/infra_tools) is my toolkit for
automating setup and operations across Debian control planes, servers,
workstations, and Proxmox guests. It combines repeatable, machine-aware
configuration with diagnostics, security hardening, deployments, coding-agent
workflows, and browser automation.

### Interactive tools and sandboxes

- [Easing Lab](https://github.com/bluehexagons/easing-sandbox) — an interactive
  browser workbench for plotting, composing, and experimenting with easing
  curves. [Open the lab](https://bluehexagons.github.io/easing-sandbox/).
- [vector-pose](https://github.com/bluehexagons/vector-pose) — vector-based
  skeletal rigging and posing software with Electron, React, and a browser
  edition. [Try the browser edition](https://bluehexagons.github.io/vector-pose/).
- [Trace Sandbox](https://github.com/bluehexagons/trace-sandbox) — an interactive
  environment for running and exploring [Trace](https://github.com/bluehexagons/trace),
  a specialized functional language developed for Antistatic.
  [Open the sandbox](https://bluehexagons.github.io/trace-sandbox/).
- [Generator](https://github.com/bluehexagons/generator) — a deterministic,
  dependency-free plasma image generator for the browser.
  [Open Generator](https://bluehexagons.github.io/generator/).
- [Pixel Generator](https://github.com/bluehexagons/pixelgenerator) — a browser
  pattern toy made in 2010. [Try it](https://bluehexagons.github.io/pixelgenerator/).
- [Waveplayer](https://github.com/bluehexagons/waveplayer) — a browser-native
  TypeScript waveform audio player with an
  [interactive demo](https://bluehexagons.github.io/waveplayer/).
- [Gomoose](https://github.com/bluehexagons/gomoose) — a minimal,
  self-contained Go web server. Its name is a pronounceable form of GoMWS: Go
  Minimal Web Server.
